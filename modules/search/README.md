# Публичный поиск

Модуль предоставляет единый публичный поиск по основным типам контента
ChurchCMS без внешнего поискового сервера.

## Что индексируется

Поиск выполняется только по данным, которые уже разрешены для публичного
просмотра:

- опубликованные публикации;
- опубликованные страницы;
- опубликованные документы с видимостью `public`;
- активные карточки людей;
- опубликованные события.

Черновики, приватные документы и другие непубличные состояния не попадают в
результаты даже при полном совпадении текста.

## Контракт

- HTML: `GET /search?q=...`;
- API: `GET /api/v1/search?q=...`;
- длина запроса: от 2 до 120 символов;
- результат ограничен 50 элементами;
- внутри каждого типа выбирается не более 20 совпадений;
- точное совпадение заголовка и совпадение с начала заголовка получают более
  высокий приоритет.

Для версии 1.0 используется bounded SQL-поиск, совместимый с PostgreSQL и
MySQL. Полнотекстовый индекс можно добавить позже как оптимизацию без изменения
публичного контракта.
