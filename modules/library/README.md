# Библиотека

Модуль `library` ведёт публичный каталог книг и других изданий ChurchCMS.

## Возможности

- organization-scoped карточки изданий;
- черновик, публикация и снятие с публикации;
- автор, издательство, год издания и ISBN;
- внутренний шифр или место хранения;
- текстовая пометка о доступности;
- краткое и полное описание с серверной очисткой HTML;
- управление через Admin Shell;
- публичный каталог и карточка издания;
- публичный API `/api/v1/library`;
- PostgreSQL и MySQL.

## Права

- `library.read` — просмотр раздела библиотеки в Admin Shell в доступной области организаций;
- `library.manage` — создание, редактирование и изменение статуса карточек в доступной области организаций.

Назначить карточку организации из другого `site_key` нельзя: ограничение проверяется доменным сервисом и составным внешним ключом базы данных.

## Публичность

В публичный HTML и API попадают только записи со статусом `published`. Черновики после снятия с публикации сразу исключаются из публичной проекции.

Полное очищенное описание передаётся только в детальной карточке. Списковая проекция содержит только данные, необходимые для каталога.

## Проверка

```bash
php tools/library-smoke.php
```

Smoke проверяет создание и обновление карточки, очистку HTML, публикацию/снятие с публикации, public projection, границу `site_key`, некорректный год и ISBN. В CI сценарий выполняется отдельно на PostgreSQL 16 и MySQL 8.4.
