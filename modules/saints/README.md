# Модуль «Святые»

Модуль хранит публичные карточки святых, связанных с конкретным приходом, монастырём, благочинием, епархией или другой организацией ChurchCMS.

## Первый срез

- организация-владелец с organization-scoped доступом;
- имя для публикации;
- чин или тип почитания;
- мирское имя;
- дни памяти в текстовом виде без навязывания календарного стиля;
- краткое житие;
- полное житие с очисткой HTML;
- управляемый порядок;
- lifecycle `draft/published`;
- Admin Shell;
- публичный каталог `/saints` и карточка `/saints/{publicId}`;
- публичный API `/api/v1/saints`;
- аудит административных действий.

Права модуля: `saints.read` и `saints.manage`.

Организация-владелец проверяется доменным сервисом и составным внешним ключом `site_key + owner_organization_public_id`. Это исключает привязку карточки к организации другого ChurchCMS-сайта.

Media-икона/портрет, календарная нормализация дней памяти, поиск, SEO и федерация должны добавляться отдельными инкрементами после стабилизации базового lifecycle.
