# Модуль «Святыни»

Модуль хранит публичные карточки святынь прихода, собора, монастыря, благочиния или епархии.

## Первый срез

- организация-владелец с organization-scoped доступом;
- тип святыни: мощи, икона, святое место, священный предмет, источник или другое;
- название и подзаголовок;
- местонахождение;
- краткое и полное описание;
- управляемый порядок;
- lifecycle `draft/published`;
- Admin Shell;
- публичный каталог `/shrines` и карточка `/shrines/{publicId}`;
- публичный API `/api/v1/shrines`;
- аудит административных действий.

Права модуля: `shrines.read` и `shrines.manage`.

Полное описание очищается общим `HtmlSanitizer`. Организация-владелец проверяется как доменным сервисом, так и составным внешним ключом `site_key + owner_organization_public_id`, поэтому святыню нельзя связать с организацией другого ChurchCMS-сайта.

Media-изображения, федерация и расширенная богословская/историческая метадата должны добавляться отдельными инкрементами после стабилизации основного lifecycle.
