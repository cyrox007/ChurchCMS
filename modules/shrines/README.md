# Модуль святынь

Модуль `shrines` хранит и публикует карточки святынь, связанных с конкретной организацией ChurchCMS.

## Что поддерживается

- типы: мощи, икона, место, предмет, источник и прочее;
- обязательная организация-владелец в рамках текущего `site_key`;
- статусы `draft` и `published`;
- название, подзаголовок, место нахождения, краткое и полное описание;
- безопасная очистка HTML через общий `HtmlSanitizer`;
- сортировка оператором;
- Admin Shell с правами `shrines.read` и `shrines.manage`;
- публичный каталог `/shrines` и карточка `/shrines/{publicId}`;
- публичный API `/api/v1/shrines` и `/api/v1/shrines/{publicId}`;
- аудит создания, редактирования, публикации и снятия с публикации;
- PostgreSQL и MySQL.

## Граница первого вертикального среза

В текущий инкремент намеренно не входят Media-обложки, отдельные галереи, федеративная синхронизация и расширенная богословская типизация. Эти возможности должны добавляться поверх стабильной карточки святыни отдельными небольшими изменениями.

## Изоляция организаций

Сервис проверяет организацию-владельца в текущем `site_key`, а составной внешний ключ БД дополнительно запрещает cross-site привязку на уровне данных.

Черновики не попадают в публичную выдачу. После снятия с публикации карточка немедленно исчезает из публичного HTML/API.
