# Расписание обучения

Модуль `education_schedules` хранит публичное расписание образовательного профиля ChurchCMS.

## Модель

Запись расписания связана с существующей образовательной программой и не дублирует организацию-владельца. Организационная область наследуется от программы.

Хранятся:

- стабильный `public_id`;
- `site_key` и ссылка на образовательную программу;
- состояние `draft/published`;
- название занятия;
- начало и окончание в UTC;
- исходный часовой пояс IANA;
- место проведения;
- текстовое примечание.

Администратор вводит локальное время и часовой пояс. Сервис переводит границы занятия в UTC, а публичная проекция возвращает ISO 8601 в исходном часовом поясе.

## Права

- `education_schedules.read` — просмотр расписания в Admin Shell;
- `education_schedules.manage` — создание, изменение и публикация.

Доступ ограничивается organization owner выбранной программы. Ручной POST с программой вне разрешённой области получает отказ.

## Публичные маршруты

- `GET /education/schedules`;
- `GET /education/schedules/{publicId}`;
- `GET /api/v1/education/schedules`;
- `GET /api/v1/education/schedules/{publicId}`.

Публично показываются только записи со статусом `published`, связанные с опубликованной образовательной программой.

## Повторяемость

Первый вертикальный срез хранит конкретные занятия. Правила повторяемости можно добавить отдельным слоем материализации, не меняя публичный контракт конкретной записи расписания.

## Проверка

`tools/education-schedules-smoke.php` проверяет PostgreSQL/MySQL, преобразование часового пояса, lifecycle публикации, скрытие расписания при снятии программы с публикации и cross-site FK.
