# Модуль «Служения и отделы»

Модуль хранит публичные карточки приходских, соборных и епархиальных служений, отделов и направлений работы.

## Возможности первого среза

- обязательная привязка карточки к организации ChurchCMS;
- черновик и публикация;
- название и краткое название;
- руководитель;
- email и телефон для публичного контакта;
- краткое и полное описание;
- управляемый порядок вывода;
- Admin Shell с organization-scoped доступом;
- публичный каталог `/ministries` и карточка `/ministries/{publicId}`;
- публичный API `/api/v1/ministries`;
- аудит создания, изменения и смены статуса.

Права модуля: `ministries.read` и `ministries.manage`.

Описание очищается через общий `HtmlSanitizer`. Владелец проверяется доменным сервисом и составным внешним ключом `site_key + owner_organization_public_id`, поэтому запись нельзя привязать к организации другого ChurchCMS-сайта.

Федерация, Media-обложки и расширенная типизация служений не входят в первый срез и должны добавляться отдельными инкрементами после стабилизации базового lifecycle.
