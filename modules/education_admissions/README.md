# Приёмная кампания

Модуль `education_admissions` хранит и публикует сведения о наборе на существующие образовательные программы ChurchCMS.

## Модель данных

Каждая запись приёмной кампании связана с `education_programs` по `site_key` и `program_public_id`. Отдельный владелец организации в модуле не хранится: область доступа наследуется от образовательной программы. Это исключает рассинхронизацию владельца программы и её приёмной кампании.

Запись содержит:

- название кампании;
- учебный год;
- даты начала и окончания приёма;
- количество бюджетных и платных мест;
- пояснение по стоимости обучения;
- требования к поступающим;
- вступительные испытания;
- контактную информацию;
- порядок вывода;
- состояние `draft` или `published`.

## Доступ администратора

Права:

- `education_admissions.read` — просмотр приёмной кампании в Admin Shell;
- `education_admissions.manage` — создание, изменение, публикация и снятие с публикации.

Организационная область вычисляется через владельца связанной образовательной программы. При ручном POST программа повторно проверяется на доступность пользователю; одного ограничения списка в форме недостаточно.

## Публичная часть

HTML:

- `/education/admissions` — опубликованные кампании;
- `/education/admissions/{publicId}` — карточка кампании.

API v1:

- `/api/v1/education/admissions`;
- `/api/v1/education/admissions/{publicId}`.

Кампания попадает в публичную проекцию только когда опубликованы одновременно сама кампания и связанная образовательная программа.

## Проверки

`tools/education-admissions-smoke.php` проверяет на PostgreSQL и MySQL:

- создание черновика;
- отсутствие черновика в публичной части;
- публикацию и публичную проекцию;
- изменение данных;
- проверку диапазона дат;
- запрет связи с программой другого `site_key` на уровне сервиса и базы;
- скрытие кампании при снятии с публикации самой кампании или образовательной программы.

CI описан в `.github/workflows/education-admissions-smoke.yml`.
