# Люди и назначения

Модуль закладывает P0-фундамент справочника людей и церковных назначений.

## Модель владения

Каждый человек имеет обязательного канонического владельца
`owner_organization_public_id` внутри того же `site_key`.

Это организация, которая отвечает за локальную карточку человека. Она не
обязана совпадать со всеми организациями, где человек служит или работает.

Каждое назначение хранится отдельно и содержит:

- стабильный public ID человека;
- стабильный public ID организации назначения;
- название должности или служения;
- машинный тип назначения;
- необязательные даты начала и окончания;
- статус и порядок отображения.

Поэтому один человек может одновременно иметь несколько назначений в
разных подразделениях одного локального организационного дерева.

## Граница сайта

Связи закреплены составными внешними ключами
`(site_key, public_id)`. Ни сервис, ни БД не позволяют назначить человеку
владельца или должность из другого `site_key`.

Новые карточки без явно указанного владельца получают корневую организацию
текущего сайта. Если корневая организация не создана, сервис не создаёт
карточку с неопределённым владельцем.
