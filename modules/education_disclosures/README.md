# Обязательные сведения образовательного профиля

Модуль `education_disclosures` хранит публичные разделы обязательной информации образовательной организации.

## Модель

Каждый раздел принадлежит существующей организации ChurchCMS и содержит:

- стабильный `public_id`;
- `site_key`;
- организацию-владельца;
- машинный `section_key`;
- название;
- краткое описание;
- очищенное HTML-содержимое;
- порядок вывода;
- состояние `draft` или `published`.

Ключ раздела намеренно не ограничен жёстким перечнем. Нормативный состав сведений может меняться, а разные образовательные профили могут использовать дополнительные разделы. На одну организацию нельзя создать два раздела с одинаковым `section_key`.

## Права

- `education_disclosures.read` — просмотр разделов в Admin Shell;
- `education_disclosures.manage` — создание, изменение и публикация.

Оба права поддерживают область организационного дерева. Пользователь не может назначить раздел организации вне своей разрешённой области или другого `site_key`.

## Публичные маршруты

- `GET /education/disclosures` — опубликованные разделы;
- `GET /education/disclosures/{publicId}` — карточка раздела;
- `GET /api/v1/education/disclosures` — публичный API;
- `GET /api/v1/education/disclosures/{publicId}` — API карточки.

Черновики никогда не попадают в публичную проекцию.

## Администрирование

Экран `/admin/education/disclosures` позволяет создать раздел, изменить его владельца в пределах доступной организационной области, содержание и порядок, а также опубликовать или снять с публикации.

Все административные изменения записываются в аудит.

## Проверка

`tools/education-disclosures-smoke.php` проверяет lifecycle на PostgreSQL и MySQL, очистку HTML, публичность, уникальность ключа раздела и cross-site защиту внешнего ключа.
