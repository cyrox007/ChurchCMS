# Образовательные программы

Модуль `education_programs` добавляет первый предметный вертикальный срез образовательного профиля ChurchCMS.

## Что хранится

Для каждой программы задаются:

- организация-владелец;
- название;
- уровень образования;
- форма обучения;
- длительность в месяцах;
- присваиваемая квалификация;
- условия поступления;
- краткое описание;
- полное очищаемое HTML-описание;
- порядок вывода;
- состояние `draft` или `published`.

## Администрирование

Раздел «Образовательные программы» появляется в Admin Shell при наличии права `education_programs.read`.

Право `education_programs.manage` разрешает:

- создавать программы;
- редактировать программу только в доступной организации;
- менять организацию-владельца только в доступном scope;
- публиковать и снимать программу с публикации.

Действия создания, изменения и публикации попадают в аудит.

## Публичная часть

Опубликованные программы доступны:

- `GET /education/programs` — каталог;
- `GET /education/programs/{publicId}` — карточка;
- `GET /api/v1/education/programs` — публичный API;
- `GET /api/v1/education/programs/{publicId}` — карточка через API.

Черновики в публичную проекцию не попадают.

## Границы первого инкремента

Этот модуль описывает именно образовательные программы. Преподаватели, кафедры, приёмная кампания, обязательные сведения, расписания, научная деятельность и Moodle/OJS реализуются отдельными модулями/интеграциями, чтобы не связывать разные предметные области в одну таблицу.
