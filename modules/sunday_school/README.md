# Модуль воскресной школы

Модуль `sunday_school` хранит и публикует карточки приходских и иных воскресных школ в общей организационной модели ChurchCMS.

## Первый вертикальный срез

Поддерживаются:

- обязательная организация-владелец в текущем `site_key`;
- статусы `draft` и `published`;
- название школы;
- руководитель;
- место занятий;
- контактный email и телефон;
- текстовая информация о возрастных группах;
- краткое и полное описание;
- безопасная очистка HTML через общий `HtmlSanitizer`;
- порядок карточек;
- Admin Shell с правами `sunday_school.read` и `sunday_school.manage`;
- публичный каталог `/sunday-school` и карточка `/sunday-school/{publicId}`;
- публичный API `/api/v1/sunday-school`;
- аудит административных действий;
- PostgreSQL и MySQL.

## Изоляция организаций

Организация-владелец проверяется доменным сервисом в текущем `site_key`. На уровне БД составной внешний ключ дополнительно запрещает привязку карточки к организации другого сайта.

Черновики не публикуются. Снятая с публикации школа немедленно исчезает из публичного HTML и API.

## Что не входит в первый срез

Учебные группы, отдельные классы, преподаватели, учебные программы и детальное расписание не смешиваются с базовой карточкой школы. Эти сущности должны развиваться отдельным инкрементом и повторно использовать будущий общий образовательный слой ChurchCMS.
