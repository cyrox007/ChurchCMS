# Научная деятельность образовательного профиля

Модуль `education_science` публикует научную деятельность образовательной организации без привязки к одному виду материалов.

## Типы активности

Первый вертикальный срез поддерживает:

- `research` — исследовательский проект;
- `conference` — конференция или научное мероприятие;
- `publication` — научная публикация;
- `grant` — грант или конкурсный проект;
- `laboratory` — лаборатория или исследовательское подразделение;
- `other` — иная научная активность.

Тип является классификацией записи, а не отдельной схемой данных. Специализированные интеграции OJS и другие научные реестры подключаются отдельными адаптерами.

## Модель

Запись содержит organization owner, тип, название, необязательный период, краткое описание, очищенное HTML-содержимое, необязательную внешнюю HTTPS-ссылку, порядок и состояние `draft/published`.

Внешние ссылки принимаются только по HTTPS. HTML проходит общий `HtmlSanitizer`.

## Права

- `education_science.read` — просмотр в Admin Shell;
- `education_science.manage` — создание, изменение и публикация.

Оба права учитывают организационную область. Владелец из другого `site_key` отвергается сервисом и составным внешним ключом БД.

## Публичные маршруты

- `GET /education/science`;
- `GET /education/science/{publicId}`;
- `GET /api/v1/education/science`;
- `GET /api/v1/education/science/{publicId}`.

Черновики не попадают в публичную выдачу.

## Проверка

`tools/education-science-smoke.php` проверяет PostgreSQL/MySQL, lifecycle публикации, очистку HTML, даты, HTTPS-ссылки и cross-site защиту.
