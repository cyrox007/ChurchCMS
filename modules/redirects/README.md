# Redirect manager

Модуль управляет точными локальными редиректами до обычной маршрутизации ChurchCMS.

## Граница безопасности

Редирект применяется только к GET и HEAD.

Источник:

- локальный абсолютный путь;
- без query string и fragment;
- не может быть /, /admin, /api, /install, /health, /media, /assets или /.well-known и их подмаршрутами;
- Unicode-пути приводятся к стабильному percent-encoded виду.

Цель:

- только локальный абсолютный путь;
- может содержать query string;
- fragment не допускается;
- внешний URL, protocol-relative URL и CR/LF отклоняются.

Поддерживаются HTTP-коды 301, 302, 307 и 308.

Активные правила не могут образовывать цепочки или циклы. Например, /old-a → /old-b запрещает активное правило /old-b → /new.

## Применение

Модуль регистрирует нейтральный pre-routing hook в Router. Поэтому правило может корректно обработать старый URL даже тогда, когда путь формально совпадает с wildcard-маршрутом другого модуля.

При срабатывании увеличивается hit_count и обновляется last_hit_at.

## Admin Shell

Раздел «Редиректы» требует redirects.manage.

Оператор может:

- создать правило;
- изменить source/target и HTTP-код;
- временно отключить правило;
- видеть число и время последнего срабатывания;
- удалить правило.

Все изменения пишутся в audit log.
