# Отложенная публикация

ChurchCMS поддерживает публикацию материала в заданный момент без внешней очереди и без обязательных дополнительных сервисов.

## Как это работает

Редактор сохраняет материал как обычно, после чего пользователь с правом публикации может:

- опубликовать материал сразу;
- выбрать локальные дату и время и запланировать публикацию;
- отменить планирование до наступления срока.

В БД запланированный материал имеет статус `scheduled`. Поле `published_at` хранит момент публикации в UTC.

Публичные страницы, API и ленты не показывают материал, пока он не станет `published`.

## Worker

Наступившие публикации обрабатываются командой:

```bash
php bin/publication-schedule.php
```

Дополнительно можно ограничить размер одной обработки и выбрать сайт:

```bash
php bin/publication-schedule.php --limit=50 --site=default
```

Worker рассчитан на запуск cron/systemd timer, например раз в минуту.

## Надёжность

Worker выбирает только записи со статусом `scheduled` и `published_at <= now`.

Переход в `published` выполняется условным UPDATE по текущему статусу. Поэтому повторный или параллельный запуск не должен повторно публиковать уже обработанную запись.

После фактической публикации:

- инвалидируется публичный page cache;
- в audit log записывается событие `publication.scheduled_published`.

## Часовой пояс

Admin Shell показывает и принимает дату/время в `app.timezone` установки.

Перед записью время переводится в UTC. Это позволяет менять серверный часовой пояс без изменения уже сохранённого момента публикации.

## Ограничения

Опубликованный материал нельзя незаметно перевести обратно в `scheduled`: сначала его нужно явно снять с публикации.

Время планирования должно быть в будущем.

## CI

`publication-schedule-smoke.yml` проверяет:

- планирование будущего времени;
- отказ для времени в прошлом;
- публикацию только наступившего материала;
- сохранение более позднего материала в `scheduled`;
- отмену планирования с возвратом в `draft`;
- идемпотентность повторного запуска worker;
- элементы управления в редакторе Admin Shell.
