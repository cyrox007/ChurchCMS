# ChurchCMS vision

ChurchCMS is a reusable content platform for:

- parishes and churches;
- cathedrals;
- monasteries;
- theological seminaries and schools;
- mixed church/education organizations.

The platform provides a common secure core and domain modules rather than a separate codebase for every website.

## Product profiles

### Small parish

Pages, news, clergy, worship schedule, media and contacts.

### Parish / cathedral

Adds ministries, events, shrines, saints, richer media, donations and prayer-request integrations.

### Theological school

Adds academic programs, teachers, departments, admissions, educational disclosures, science/publications and integrations with systems such as Moodle/OJS.

## Migration

The legacy VPDS CMS is a data and behavior reference only. Its runtime architecture is not carried forward.

ChurchCMS migration tooling will map legacy content, files, URLs and selected user data into the new model while preserving redirects and historical content.
