# Интеграция с Новости Mail

ChurchCMS 1.0 готовит отдельный партнёрский контур `news_mail`, не подменяя внешнее согласование с Mail.

## Подтверждённое публичное требование

Официальная помощь Новости Mail указывает, что представитель СМИ должен подать заявку на партнёрство. Новости Mail публикует материалы партнёрских СМИ, но открытая техническая спецификация партнёрского API или XML-формата в публичной помощи не закреплена.

Поэтому ChurchCMS не использует недокументированные endpoint'ы и не утверждает, что собственный RSS уже является официальным протоколом Mail.

## Технический фид

После включения target `news_mail` ChurchCMS формирует `/feeds/news-mail.xml` — стандартный полнотекстовый RSS 2.0 с `content:encoded`. Он предназначен для внутренней проверки и передачи партнёру при согласовании способа доставки.

Для каждого материала передаются стабильный идентификатор, заголовок, канонический URL, дата публикации, краткое описание, полный HTML-текст, автор, категории и изображение `enclosure`, когда оно задано.

## Настройка

В `config/local.php`:

```php
'syndication' => [
    'site_url' => 'https://example.org',
    'targets' => [
        'news_mail' => [
            'enabled' => true,
            'partner_approved' => false,
            'delivery_contract_confirmed' => false,
        ],
    ],
],
```

`partner_approved` выставляется только после одобрения заявки представителя СМИ. `delivery_contract_confirmed` выставляется только после того, как Mail подтвердит конкретный технический способ передачи материалов. Пока хотя бы один из этих флагов не подтверждён, административная диагностика возвращает состояние `partner_access_required`.

## Редакционный контур

На странице «Каналы» конкретной публикации можно включить или выключить «Новости Mail». После включения доступны общие target-specific переопределения заголовка, описания и изображения. Формы используют существующий AJAX/progressive-enhancement слой Admin Shell и сохраняют обычный серверный POST как резервный сценарий.

## Проверка

Административный валидатор проверяет техническое качество фида без сетевых запросов: XML/RSS 2.0, UTF-8, данные канала, наличие материалов, полный текст, URL, даты, повторы ссылок и изображения.

Успешная техническая проверка не означает автоматического принятия Новости Mail. Финальное соответствие формату нужно сверить с требованиями, которые партнёр сообщит после рассмотрения заявки. Если они отличаются от стандартного полнотекстового RSS, адаптер ChurchCMS меняется по официально полученной спецификации, а не по обратному проектированию закрытых endpoint'ов.
