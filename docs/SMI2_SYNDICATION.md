# Интеграция со СМИ2

ChurchCMS 1.0 формирует отдельную полнотекстовую RSS 2.0-ленту для партнёрского контура СМИ2.

## Что подтверждено публично

Публичная инструкция объединённого партнёрского отдела «МирТесен»/СМИ2 просит издателя предоставить полнотекстовую RSS-ленту. Отдельная открытая XML-схема СМИ2 с обязательными приватными тегами на момент реализации не опубликована.

Поэтому ChurchCMS не использует недокументированные API или поля. Полный текст передаётся стандартным RSS-модулем `content:encoded`.

## Включение

В `config/local.php`:

```php
'syndication' => [
    'site_url' => 'https://example.org',
    'targets' => [
        'smi2' => [
            'enabled' => true,
            'partner_approved' => false,
        ],
    ],
],
```

После включения техническая лента доступна по адресу `/feeds/smi2.xml`.

`partner_approved` нельзя выставлять в `true` заранее. Этот флаг означает, что партнёрский отдел подтвердил подключение конкретного сайта.

## Состав материала

Для каждого материала в фиде передаются:

- стабильный `guid`;
- заголовок;
- канонический абсолютный URL;
- дата публикации;
- краткое описание, если оно заполнено;
- полный HTML-текст в `content:encoded`;
- автор, если он заполнен;
- категории;
- изображение через `enclosure`, если оно настроено.

Переопределения заголовка, описания и изображения для target `smi2` используют общий механизм target-specific overrides ChurchCMS.

## Диагностика

В административном разделе журнала экспортов доступна проверка СМИ2. Она не выполняет сетевые запросы и проверяет:

- корректность XML и RSS 2.0;
- UTF-8 и Content-Type;
- данные канала;
- наличие хотя бы одного материала;
- заголовок, URL и дату каждого материала;
- обязательный полный текст `content:encoded`;
- отсутствие повторяющихся URL;
- корректность `enclosure` и MIME изображения.

Если фид технически исправен, но партнёр ещё не подтвердил подключение, ChurchCMS показывает диагностический код `partner_access_required`. Это не ошибка реализации и не повод обходить партнёрскую процедуру.

## Передача партнёру

1. Включить target `smi2` на тестовой/production-конфигурации с каноническим HTTPS URL.
2. Убедиться, что в ленте есть разрешённые для СМИ2 публикации.
3. Открыть административную проверку и устранить ошибки.
4. Передать партнёрскому отделу URL `/feeds/smi2.xml` вместе с другими запрошенными материалами.
5. После фактического подтверждения подключения выставить `partner_approved => true`.

Публичная инструкция партнёрского отдела также упоминает логотип 100×100, шапку 1000×240, субдомен, идентификаторы счётчиков и установку партнёрского виджета. Эти действия относятся к внешнему онбордингу и не подменяются кодом ChurchCMS.
