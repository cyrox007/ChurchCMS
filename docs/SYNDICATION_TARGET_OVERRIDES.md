# Переопределения публикаций по каналам синдикации

ChurchCMS позволяет задать отдельное представление одной публикации для каждого включённого канала внешнего распространения.

## Приоритет значений

Для заголовка и краткого описания применяется следующий порядок:

1. значение для конкретного канала;
2. общее значение синдикации публикации;
3. обычный заголовок или краткое описание публикации.

Таким образом, отсутствие настройки для канала не меняет существующее поведение.

## Изображение

Для канала можно указать отдельное изображение. Требования:

- только абсолютный HTTPS-адрес;
- вместе с URL обязательно указывается MIME-тип вида `image/jpeg`, `image/png`, `image/webp` и т. п.;
- если URL изображения пуст, MIME-тип не используется.

RSS и Rambler передают такое изображение через `enclosure`.

## Хранение

Переопределения хранятся отдельными строками `publication + target`. Добавление нового канала не требует добавления новых колонок в таблицу публикаций.

Если все значения конкретного канала очищены, строка переопределения удаляется, а публикация снова использует общий fallback.

## Администрирование

Пользователь с правом `publications.edit` и доступом к организации-владельцу публикации открывает раздел **Публикации → Каналы**.

Форма показывает только те каналы, которые уже выбраны для публикации. Параметры постороннего канала, подставленные вручную в запрос, не сохраняются.

Изменение фиксируется в аудите событием `publication.syndication_overrides_updated`.
