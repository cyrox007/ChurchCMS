# Журнал экспортов синдикации

ChurchCMS фиксирует попытки фактического формирования RSS и Rambler-фидов. Повторная выдача уже подготовленного фида из кэша новой записью не считается.

## Что сохраняется

Для каждой генерации сохраняются:

- целевой канал (`rss` или `rambler`);
- результат `success` / `failed`;
- число материалов, подготовленных для фида;
- размер сформированного ответа в байтах;
- длительность формирования в миллисекундах;
- безопасный код ошибки без текста исключения;
- время события в UTC.

Содержимое публикаций, XML-фид, секреты и текст исключений в журнал не записываются.

## Просмотр

Администратор с правом `publications.read` открывает **Публикации → Журнал экспортов**. Экран показывает до 200 последних записей и позволяет отфильтровать их по RSS или Rambler.

## Отказоустойчивость

Журнал является наблюдаемостью, а не обязательной частью публичной выдачи. Если запись телеметрии в БД не удалась, успешно сформированный фид всё равно отдаётся пользователю. Если ошиблось само формирование, ChurchCMS пытается записать событие `failed`, после чего исходная ошибка продолжает обрабатываться обычным механизмом ошибок приложения.
