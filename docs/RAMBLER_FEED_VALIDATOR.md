# Проверка Rambler-фида

ChurchCMS содержит локальный валидатор фида для Rambler/новости. Он проверяет сформированный XML перед передачей партнёру и доступен в Admin Shell через **Публикации → Журнал экспортов → Проверить Rambler**.

Проверки основаны на актуальных правилах оформления новостного потока Rambler/новости, опубликованных в справке Рамблера.

## Обязательные проверки

Валидатор проверяет:

- XML-декларацию версии 1.0 с кодировкой UTF-8;
- `Content-Type: application/rss+xml; charset=utf-8`;
- корректность XML;
- RSS версии 2.0;
- наличие ровно одного `channel`;
- обязательные `channel/title` и `channel/link`;
- наличие хотя бы одного `item`;
- обязательные `item/title` и `item/link`;
- обязательный полный текст в `content` или `full-text`;
- абсолютные HTTP/HTTPS-ссылки;
- уникальность ссылок публикаций внутри фида;
- формат `pubDate` по RFC-2822, если поле присутствует;
- корректность URL у `enclosure`.

## Предупреждения

Отдельным предупреждением отмечаются:

- отсутствие пространства имён Rambler;
- повторяющийся `guid`;
- изображение `enclosure` с MIME-типом вне PNG/JPEG/PJPEG/WEBP/AVIF.

Предупреждение не делает фид формально непригодным, но требует проверки оператором.

## Ограничения

Проверка выполняется локально и намеренно не делает сетевых запросов. Валидатор не проверяет:

- доступность URL публикации или изображения извне;
- фактический размер изображения (по правилам Rambler — не более 5 МБ);
- реальный формат файла по содержимому удалённого ресурса;
- решение партнёрской системы принять или отклонить источник.

Это исключает SSRF-риск и делает проверку воспроизводимой в CI.
